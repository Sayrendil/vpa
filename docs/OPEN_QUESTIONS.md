# Открытые вопросы к Артуру

Пока решения нет, SI-01 отвечает «это ещё не зафиксировано» или передаёт вопрос администрации.

1. **Behavioural architecture SI-01.** Её текст заменит раздел «Характер» в `prompts/system.md`; сейчас там черновик по VPAI v0.3.
2. **Описания комнат.** Есть только у Дом VPA, VPA — Обсудим, К-Медиа (взяты из v0.3). Для К-Кино, Бар, К-Места,
   К-Сознание и реальность, К-Книги, К-Действие, Любовь и отношения нужно 1–3 предложения → `config/facts.yaml`.
3. **Активность комнат** (active / low / sleeping). Сейчас у всех `unknown` — бот не говорит, где живо, а где нет.
4. **Возраст.** Порог не задан (`entry.age: NEEDS_DECISION`).
5. **Возврат денег.** В ответах Артура не упомянут; в `facts.yaml` взято из v0.3: «возврат не предусмотрен». Подтвердить.
6. **Повторное вступление после окончания подписки (EXPIRED).** Нужна ли новая проверка? Сейчас бот передаёт просьбу админам.
7. **Повторная попытка после отказа (REJECTED).** Сейчас: только через администрацию (`/approve <id>` вручную).
8. **Ссылка Tribute открытая?** Если человек оплатит без проверки, бот только пишет предупреждение в админ-чат. Можно ли
   закрыть ссылку или выдавать персональную?
9. **Неуспешное списание.** У Tribute нет вебхука «платёж не прошёл» — есть только new/renewed/cancelled.
   Бот видит лишь, что `expires_at` прошёл, а продления нет, и не утверждает, открыт ли доступ. Если нужно точнее —
   опрашивать API Tribute.
10. **Какие каналы входят в подписку** и какие `subscription_id` у VPA в Tribute → `TRIBUTE_SUBSCRIPTION_IDS`.
11. **Распознавание голосовых.** Нужен STT-провайдер (OpenAI / Groq / свой сервер). Это ещё одна передача данных
    наружу — учесть в политике данных. Пока выключено, бот просит писать текстом.
12. **Политика обработки данных.** Нужен короткий документ (что собираем, зачем, кто видит, сроки, внешняя AI-модель,
    как удалить) и ссылка на него — бот пока говорит, что удаление идёт через администрацию.
